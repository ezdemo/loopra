Loopra

推理循环 · 工具调用 · 子代理协作 · 双端工作台

Loopra 将用户任务、模型推理与受控工具调用组织成持续执行循环：读取项目上下文，搜索、编辑或构建代码， 消费执行结果后继续推理，直至完成任务或需要用户决策。提供 Web 与 Electron Desktop 工作台， 适合在本地代码库中完成开发、排障、测试、文档整理和多步骤协作。

快速开始

三步上手

安装、启动、配置模型渠道，即可在你的代码库中开始使用。

1

安装

一键脚本安装 CLI，桌面端可从 Releases 下载；国内网络推荐使用镜像加速。

直连源 
irm https://raw.githubusercontent.com/ezdemo/loopra-release/main/.release/setup.ps1 | iex
镜像加速国内推荐 
irm https://raw.githubusercontent.com/ezdemo/loopra-release/main/.release/setup-mirror.ps1 | iex
直连源 
curl -fsSL https://raw.githubusercontent.com/ezdemo/loopra-release/main/.release/setup.sh | bash
镜像加速国内推荐 
curl -fsSL https://raw.githubusercontent.com/ezdemo/loopra-release/main/.release/setup-mirror.sh | bash
2

启动服务

使用 0 让服务自动选择可用端口，控制台会输出本地访问地址。

loopra web 0
3

配置模型渠道

在 Web 设置页维护模型渠道，或直接编辑 ~/.loopra/config.json，配置 API Key 后重启服务。

{
  "model": "deepseek-v4-flash",
  "modelChannelId": "default",
  "modelChannels": [
    {
      "id": "default",
      "name": "Default",
      "baseUrl": "https://api.deepseek.com/v1",
      "apiKey": "sk-your-api-key",
      "apiProtocol": "chat_completions",
      "models": [
        {
          "name": "deepseek-v4-flash",
          "contextTokens": -1,
          "imageInput": false
        }
      ]
    }
  ],
  "workspaceDir": "/path/to/your/project"
}
镜像脚本与安装包仍从 GitHub 下载，仅加速脚本拉取，适合国内网络。 每个渠道独立维护 API 地址、密钥、协议与模型能力，apiProtocol 支持 chat_completions 和 responses。 首次启动会在 ~/.loopra/config.json 创建默认配置。
核心能力

为真实开发场景设计的完整能力

从推理循环到审批边界，从上下文管理到桌面工作台。

自主推理循环

流式输出推理、工具调用和结果，持续处理多轮任务。

上下文管理

JSONL 会话持久化、自动摘要折叠、消息自愈和 token 用量统计。

多模型渠道

支持多渠道、Chat Completions API、OpenAI Responses API、推理强度和模型能力配置。

可扩展工具系统

通过 Solon @ToolMapping 声明式注册，支持内置工具、MCP、OpenAPI、技能和 REST API。

代码库操作

在项目边界内读取、搜索、编辑文件，运行一次性或交互式命令。

子代理协作

内置 explore、implement、test、review、plan 五种角色，支持隔离上下文、权限约束和超时控制。

计划模式

输入框一键进入只读探索，探索完成后提交计划供用户审查，批准后按计划执行。

持久协作状态

Checklist、会话级 Goal、项目记忆和共享上下文支持长任务及父子代理协作。

审批与边界

三态 HITL（free / approval / auto）、工具白名单、路径边界保护，以及可选的独立校验模型。

桌面工作台

Electron Desktop 提供多聊天标签、Git/文件面板、元素检查、服务进程管理和 AI 浏览器。

工具系统

武装到牙齿的内置工具

工具由 Solon 自动发现，可在工具管理界面启用、禁用，并为自定义工具指定只读或写入分类。

分类覆盖场景
文件与代码检索 read、write、edit、glob、grep、ls、java_source、codesearch
命令与网络 bash、交互式命令会话、webfetch、call_api
任务协作 sub_agent、checklist_*、goal_*、workspace_*
项目状态 memory 将跨会话事实保存到 .loopra/loopra-memory.md；共享上下文保存到 .loopra/workspace/
多模态与浏览器 read_image，以及桌面端可见 AI 浏览器的 browser_* 工具
MCP、OpenAPI 和技能可为 Agent 注入额外工具。read_image 支持项目路径、绝对路径、Base64/data URI 和 HTTP(S) URL，单张图片最大 5 MiB。 浏览器工具只操作可见的 Desktop 浏览器；遇到登录、验证码或安全验证时，Agent 会请求用户接管，不会代填或读取敏感凭据。
架构

插件化外挂，按需取用

cutin-core 提供插件化 Agent 运行时；loopra 基于它实现完整的 Loopra 业务层。

核心引擎

cutin-core

默认循环引擎、模型网关/Provider、拦截器、Hook、工具注册表、插件打包与生命周期，是 Loopra 全量能力的外挂宿主。

业务层

loopra

LoopraAgent 门面、内置工具、Goal/Checklist/项目/命令/会话/配置、MCP/OpenAPI/Skill 桥接、定时任务、ACP 与 Solon Web 接口。

前端 & 桌面

loopra-front

Vue 前端与 Electron Desktop。

文档

intro / docs

官网内容与项目文档，随仓库一同维护。

cutin-core
     ↑
loopra   （LoopraAgent / 内置工具 / Goal / 项目 / MCP / Skill / ACP / Web）
  • 需要定制 Agent 运行时 → 实现 cutin-core 插件，注册生命周期拦截器。
  • 需要开箱即用的完整 Loopra → 运行 loopra，通过 cutin 插件扩展。
  • 需要把 Agent 暴露为 ACP Agent → loopra 已内置。

前置条件
JDK 17
Maven 3.9+
Node.js 18+
pnpm 8+
启用 ACP（Agent Client Protocol） 
# stdio 模式
loopra web 0 --loopra.acp=true

loopra web 0 --loopra.acp=true --loopra.acp.ws.port=8765
后端构建与测试 
# 构建后端模块
mvn clean package

# 运行全部后端测试
mvn test

# 仅验证 Web 模块及其依赖模块
mvn -pl loopra -am test
前端与 Desktop 
cd loopra-front
pnpm install

# 启动前端开发服务
pnpm dev

# 运行前端测试并构建
pnpm test -- --run
pnpm build

# 启动 Electron 开发模式
pnpm dev:electron
