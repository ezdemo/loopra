# Loopra 插件源

将此目录的内容放到 GitHub 仓库（如 `ezdemo/loopra-plugins`），提交后即可在 Loopra 的「技能与插件 → 插件 → 发现」中使用。「插件」是顶部默认选中的选项。

每个插件放在 `plugins/<目录名>/` 下，包含具有唯一 `name` 的 `package.json` 和插件入口。`description`、`version` 显示在列表中。无需维护索引文件。

添加插件后，在 Loopra 中刷新列表，点击「安装」。在「插件 → 我的内容」中启停、设置、更新或卸载，发现页也可直接更新、卸载已安装的外部插件；移除源会保留已安装插件。

发布新版时保持 `package.json.name` 不变，更新 `version`、入口和资源，再提交到用户安装时选择的分支或标签。用户点击「更新」后会从原来源重新获取，保留配置、数据和启停状态；固定标签不会自动切到新标签，失败时保留旧版。更新成功通过短暂的顶部通知反馈，不占列表位置。刷新列表只更新发现信息，不替换已安装插件。版本规则和接口见[更新与版本](../../docs/PLUGIN.md#更新与版本)。

工具、Hook 优先级与合并规则、图标、设置页、纯聊天右侧插件面板和宿主服务见[插件开发文档](../../docs/PLUGIN.md)。
