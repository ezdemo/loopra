## 本轮修复

1. 解除后加载 CSS 对抽屉定位的覆盖：≤1100px 时右侧面板覆盖主区，不再挤压聊天区。
2. 增加抽屉遮罩、点击遮罩关闭与 Escape 关闭；弹窗内 Escape 不影响下层面板。
3. 限制桌面停靠面板最大宽度，避免拖动或恢复宽度后聊天区过窄。
4. 根据聊天区实际宽度压缩顶栏，修复连接状态、面包屑和操作按钮互相挤压。
5. 调整侧栏、导航、项目行、首页标志和输入框比例；去掉浏览器页面模拟窗口的圆角边框。
6. 隐藏的项目操作按钮不再常驻占位，项目名称恢复可读；项目路径可通过标题提示查看。
7. 增加可访问的单项目展开/折叠按钮和 Ctrl/⌘+B 侧栏快捷键，并更新快捷键说明。
8. 简化侧栏底部入口，统一文件夹/终端图标和菜单文字。
9. 补齐工具搜索框样式、卡片间距和复选框尺寸，修复通用输入框样式把复选框拉满宽度的问题。
10. 设置标题操作分组、窄内容区表单换行、网格自适应；大字号下不再横向溢出。
11. 将聊天悬浮控件限制在主区层叠上下文；打开面板或弹窗时暂时隐藏宠物，避免遮挡。

## 浏览器验收

- 连接本地真实后端，对照打开 legacy 与 React 页面。
- 实测 390px、768px、959px、1280px 视口，检查页面无横向溢出。
- 1280px 停靠面板宽 452px，侧栏宽 256px，聊天区宽 572px。
- 768px 面板为 absolute 抽屉，聊天区保持 528px，页面总宽仍为 768px。
- 实测项目折叠、Ctrl+B、抽屉遮罩关闭、聊天历史与代码块展示。
- 检查手机设置分类、工具搜索、MCP 新增草稿和复选框，复选框为 16×16px。
- 检查浅色/深色主题、模型供应商新增草稿、150% 缩放与设置滚动；验收后恢复浅色及 100% 缩放。
- `pnpm test:web`：281 项通过；`pnpm build`：通过。

本轮没有发送真实模型请求，也没有保存模型/集成草稿、安装资源、提交 Git 或删除服务端数据；这些写入路径的验证依据现有自动测试和代码检查。

## 仍存在的边界

侧栏精简调整：顶部仅保留新建会话和搜索，底部仅保留设置。技能、工具、子代理、用量与主题仍从设置访问；会话管理和需求池放在“工作区与数据 → 工作区”，帮助中心放在“连接与帮助 → 关于与存储”，均可通过设置搜索找到。批量折叠工作区改用折叠/展开图标，提示文字随状态变化。

- 原生终端、系统文件管理器、文件拖出与窗口控制依赖 Electron 桥接；默认 Web 入口提供文件预览和后台命令查看。它们属于运行环境差异。
- Vue 隔离环境的手动合并等操作也调用 Electron `gitEnvironment` 桥接，不能视为 legacy 浏览器页面具备而 React Web 遗漏的能力。
- 当前语言切换覆盖侧栏和输入框，管理页面尚未完整翻译；本轮没有将其扩展为全量国际化。
- 会话隐藏/恢复为浏览器本地状态，上下文用量为估算。这两项没有因界面修复改成新的后端能力。
